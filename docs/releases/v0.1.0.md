# 期限くん v0.1.0 — 初回公開

[期限くんを開く](https://deadlineapp.zuiken.workers.dev/)

期限から逆算して「今日何をどこまで進めたか」を記録する、スマートフォン向けのPWAを公開しました。

## 主な機能

- 目標と期限を設定し、残り日数・期間中の休日数・目標全体の達成度を確認
- TODOの追加、完了チェック、編集、削除
- TODOごとにページ番号や問題番号の範囲を設定し、現在の番号から達成率を自動計算
- オフラインでの基本操作と、オンライン時の日本の祝日取得
- 時刻を選べる期限リマインダーとテスト通知
- 初回チュートリアル、設定画面、任意の同意に基づく利用状況の計測
- 画面下部にバージョンとビルド元コミットIDを表示

## 今回の仕上げ

- iPhoneで時間指定通知が拒否されていた`Topic`ヘッダーを除去
- 進捗の数値範囲がページだけでなく問題番号にも使えることを画面で明確化
- 公開URLとCloudflare Workersを中心にREADMEを整理

## 知っておいてほしいこと

目標とTODOは利用中の端末内に保存されます。端末間同期とバックアップはまだありません。通知はネットワークと端末の通知許可が必要です。iPhone/iPadでは、Safariからホーム画面に追加したアプリで通知をオンにしてください。
